NotoSans-Regular.ttf is the unmodified Noto Sans regular font from:
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

The SIL Open Font License is included as OFL.txt. The font supports Latin,
Greek and Cyrillic. Scripts and glyphs absent from this font are rejected
explicitly rather than silently rendered as missing-glyph boxes.
